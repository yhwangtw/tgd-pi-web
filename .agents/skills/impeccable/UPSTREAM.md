# Impeccable source

Project-local Codex skill from [pbakaus/impeccable](https://github.com/pbakaus/impeccable), commit `9d715cc4f5564a990ca8345abfdd5df6dc9b41c8` (skill version 4.4.0). The `LICENSE` and `NOTICE.md` files are copied from that commit.

The skill is available as `$impeccable` after Codex reloads its project skills. Its optional automatic edit hook is not installed; design checks run when the skill is invoked.

The three reference files `extract.md`, `harden.md`, and `optimize.md` have only trailing whitespace and end-of-file blank lines normalized so this project's diff check passes. The launcher retains its upstream executable mode.
